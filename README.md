# FoodSave

FoodSave is a food inventory and waste tracking application designed to help users manage food stock, monitor consumption, and reduce food waste.

## Features

- Food inventory management
- Track food consumption
- Monitor food waste
- Dashboard with inventory statistics
- Low-stock alerts
- Expiry date monitoring
- Waste analytics and reports
